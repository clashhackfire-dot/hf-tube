# HF-Tube

An open-source, YouTube-focused media downloader for Android, built by [HackFire](https://github.com/clashhackfire-dot).

HF-Tube is a client-side extraction tool. It does not host, store, or distribute any copyrighted media — it automates what a browser plus a local extraction tool can already do, wrapped in a clean mobile UI.

## Status

🚧 Early development. Not yet functional — repo currently just scaffolding.

## Planned features

- Sign in with your own Google account via an in-app WebView (keeps requests looking like a normal signed-in browser session, and surfaces your real, personalized YouTube feed inside the app)
- Native YouTube feed tab
- Search & download tab
- Format picker (audio-only or a choice of video quality)
- Download queue with pause/resume, live progress, and speed
- Fully original color theme and branding — not a reskin of any existing app

## Why this exists

Most closed-source "tube downloader" apps ask for a lot of trust with none of the transparency. HF-Tube aims to do the same job in the open: auditable code, no bundled analytics or telemetry, no ads, no closed binary blobs.

## Building

Developed entirely on-device using Termux (no PC/desktop toolchain). Build instructions will be added here once the project scaffold and build tooling are in place.
